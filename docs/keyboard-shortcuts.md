# Keyboard shortcuts

## Global

| Key | Action |
|---|---|
| `?` | Help |
| `r` | Refresh |
| `q` | Quit |
| `Ctrl+C` | Quit |

## Containers

| Key | Action |
|---|---|
| `j` / `Down` | Next container |
| `k` / `Up` | Previous container |
| `Enter` / `i` | Inspect |
| `/` | Filter |
| `s` | Start |
| `x` | Stop |
| `R` | Restart |
| `p` | Pause / Unpause |
| `d` | Remove |

## Inspect

| Key | Action |
|---|---|
| `Esc` / `q` | Back |
| `j` / `k` | Scroll |

## Confirmations

| Key | Action |
|---|---|
| `y` / `Enter` | Confirm |
| `n` / `Esc` | Cancel |
